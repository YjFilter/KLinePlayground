## 推荐拆分原则

- 前端 HTML/CSS/JS 与后端服务尽量分给不同 Worker。
- 测试文件跟随其对应实现 Worker，避免两个 Worker 同时修改同一测试。
- 主路由、交易引擎、持久化和跨模块集成保留给主 Agent。
- 一个 Worker 最好只改 1–4 个文件，并能在独立专项测试中验收。
